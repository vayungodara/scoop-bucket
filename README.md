# Scoop bucket

Windows packages for [cliproxy-rs](https://github.com/vayungodara/cliproxy-rs).

```powershell
scoop bucket add vayungodara https://github.com/vayungodara/scoop-bucket
scoop install vayungodara/cliproxy-rs
```

Scoop installs the binary only. It doesn't write a config or start the proxy; see [INSTALL.md](https://github.com/vayungodara/cliproxy-rs/blob/master/docs/INSTALL.md) for that, or use the PowerShell installer.
